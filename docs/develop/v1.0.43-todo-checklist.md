# v1.0.43 待完成清单

扫描日期：2026-05-14

对照文档：`docs/develop/类Obsidian软件最终可落地方案（本地优先+多端同步+AI知识库版）_v1.0.43.md`

本文只记录“距离方案可落地仍未完成或未收口”的事项，不重复已完成能力。优先级含义：

- `P0`：阻塞 V1 对外发布或会造成产品入口/数据安全/同步一致性风险。
- `P1`：V1 应补齐，允许短期以明确降级文案交付，但不能长期算完成。
- `P2`：体验增强或 V1.1 可排期。
- `Deferred`：方案明确可延后，当前不阻塞桌面 V1。

## P0：V1 发布阻塞项

### 1. 产品入口与多工作区模型未收口

当前状态：

- 主导航只开放“笔记库浏览 / AI 文档 / 回收站 / 设置”。
- 同步页、冲突页、AI Wiki 页、图谱页代码仍在，但未作为稳定产品入口统一开放。
- 顶部工作区切换器代码存在，但当前被隐藏且内部使用空实现。
- 设置页仍保留旧 `/api/workspace/select-folder` 单工作区入口，与新 `/api/workspaces/*` registry 模型并存。

待完成：

- 决定同步页、冲突页、AI Wiki 页、图谱页是隐藏、移除，还是补齐后开放。
- 将所有工作区选择、切换、删除、重命名入口统一到 `/api/workspaces/*`。
- 顶部工作区切换器接入真实 registry 状态，移除空 stub。
- 工作区注册项补齐重命名、失效路径修复、元数据编辑和错误提示。

验收：

- 主导航只出现已接真实工作流的页面。
- 设置页和顶部入口操作同一套 active workspace。
- 切换工作区后，文件树、搜索、回收站、AI 上下文、同步状态全部刷新到新工作区。

### 2. 应用内移动笔记未完成

当前状态：

- 新建、删除、重命名 Markdown 文档已有闭环。
- 当前重命名只允许修改文件名，不允许跨目录移动。

待完成：

- 增加应用内移动笔记能力。
- 移动必须保持同一 `file_id`，不能退化为“删除 + 新建”。
- 移动后需要更新 filemap、搜索索引、双链索引和同步待提交状态。
- 覆盖同名冲突、目录不存在、跨目录权限失败等错误。

验收：

- 应用内重命名 / 移动后，同一 `file_id` 保持不变。
- 同步 manifest 中体现 path 变更，而不是 delete + new。
- 与方案 §17.2 test 11 对齐。

### 3. 真实 E2EE 未完成

当前状态：

- `clients/desktop/crypto.py` 仍为 placeholder。
- 当前“加密”只是明文 payload 加确定性 tag，不满足 E2EE。

待完成：

- vault key / content key 派生。
- blob 加密与解密。
- 确定性或受控 nonce 策略。
- 本地密钥安全存储。
- 错误密码、恢复包、恢复短语流程。
- 与 manifest、blob 去重、上传下载联调。

验收：

- 服务端和对象存储只看到密文。
- 错误密码不能解密，且 UI 给出明确提示。
- 新设备必须通过恢复包/恢复短语接入。
- 缺少恢复材料时明确提示数据不可恢复。

### 4. 断点续传未完成

当前状态：

- 后端提供一次性 blob upload/download capability。
- 未发现 chunk、range、resume、Content-Range 等断点续传协议。

待完成：

- 设计并实现大 blob 分片上传。
- 支持上传中断后续传。
- 支持下载中断后重试或续传。
- 前端显示大附件上传进度、失败重试和大小限制。

验收：

- 上传中断恢复后不会重复提交不完整 blob。
- 客户端能验证最终 encrypted_size/content_hash。
- 与方案 §17.2 test 7 对齐。

### 5. 设备管理与 tombstone 回收闭环未完成

当前状态：

- 后端有设备注册、删除、ack primitives。
- 没有完整设备列表 UI、heartbeat/last_seen、每设备 ack 展示、失活候选状态和 tombstone GC 产品闭环。

待完成：

- 设备列表接口和 UI。
- heartbeat / last_seen_at。
- 每设备 acked_revision 展示。
- 移除设备确认流。
- 移除设备后 token/capability 立即吊销。
- 基于所有活跃设备 ack 判断 tombstone 可回收。
- tombstone 回收执行、日志和可解释提示。

验收：

- 设备删除后原 token 与未使用 download capability 立即失效。
- 新注册但未加入 vault 的设备不阻塞该 vault tombstone 回收。
- 设备首次 commit/ack 后才参与该 vault tombstone 判定。
- 与方案 §17.2 test 21、22、26、27、55、59 对齐。

### 6. 生产后端未完成

当前状态：

- `apps/backend/noteapp-server` README 明确标注为 local-development MVP。
- 当前状态存储在本地 `.data/`，不是生产数据库。
- README 明确列出无账号模型、无 durable database、无真实对象存储、无 token expiry、无 tombstone GC、无跨进程 CAS 锁。
- 为本地 bootstrap，部分 API 仍允许无 Authorization。

待完成：

- 正式账号模型。
- 持久数据库。
- 真实对象存储。
- access token / refresh token 过期与刷新。
- 移除本地无 Authorization 放宽逻辑。
- 跨进程 / 多实例 CAS 锁。
- 部署、迁移、监控、备份策略。

验收：

- 无授权请求全部被拒绝。
- 多进程或多实例并发 commit 不破坏 CAS。
- 对象存储短时不可用时客户端可解释降级。
- 与方案 §17.2 test 9、15、16 对齐。

## P1：V1 应补齐项

待完成：

- PDF 基础预览或外部打开入口。

验收：

- 附件跨端同步后可打开。
- 删除/恢复附件不会破坏 filemap 或 tombstone 语义。

### 8. AI 输出写回未完成

当前状态：

- AI 文档支持文件夹 / 多选文档上下文、多轮会话和本地持久化。
- 当前输出模式仍是 `preview`。
- 没有“插入当前笔记”或“保存为新知识页”动作。

待完成：

- AI 回答插入当前笔记。
- AI 回答保存为新的 `.ai/wiki/` 或普通知识页。
- 写回前 diff / 确认流。
- `locked: true` / `user_edited: true` 页面保护。
- 写回后刷新文件树、搜索索引、双链索引和同步状态。

验收：

- AI 回答默认附来源。
- 写回不会覆盖用户编辑过的知识页。
- 写回失败不影响本地编辑和同步。

### 9. AI 总结入口未完整产品化

当前状态：

- AI 文档页可基于文件夹或多选文档执行任意指令。
- 缺少明确的“当前笔记总结”“搜索结果总结”入口。
- Ask / AI 文档回答尚非流式输出。

待完成：

- 当前笔记总结入口。
- 文件夹总结入口产品化。
- 搜索结果总结入口。
- 流式回答。
- provider 失败诊断详情，例如状态码、请求 ID、模型响应摘要。

验收：

- 当前笔记、文件夹、搜索结果都能进入统一 AI 上下文。
- AI 服务不可用时优雅降级，不影响本地编辑与同步。
- 依据不足时拒答并给出来源不足说明。

### 10. 同步页和冲突页未作为稳定入口收口

待完成：

验收：

- 保存后能明确引导“本地已修改 / 待同步”状态。
- 提交冲突后，用户可以先拉取远端基线，再继续提交本地变更。
- 拉取后本地冲突副本可见、可清理。
