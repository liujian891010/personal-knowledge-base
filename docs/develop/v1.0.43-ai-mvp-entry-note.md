# v1.0.43 AI MVP 进入记录

日期：2026-05-11

## 当前决策

附件/资源管理 MVP 暂缓，不作为 AI 知识库第一阶段的前置阻塞项。

## 暂缓范围

- 图片导入与预览
- PDF 导入与解析
- 任意附件复制到 Vault
- 附件进入 filemap 后的完整 CRUD/回收站体验
- 附件内容进入 AI 编译上下文

## AI 知识库第一阶段范围

先进入本地 Markdown 笔记的 AI 知识库 MVP：

- 读取当前 Vault 中 active Markdown note
- 本地确定性编译 `.ai/wiki/*.md`
- 生成 `.ai/index.md`
- 将生成产物写入 filemap，类型为 `ai_wiki` / `ai_index`
- 前端提供 “AI 知识库” 入口和 “编译 AI Wiki” 操作

## 边界说明

第一阶段不调用外部 LLM，不承诺模型级总结质量。目标是先建立稳定的 AI 产物层、路径约定、filemap 联动和 UI 入口。后续再在该产物层之上接入本地模型、远程模型、问答和结构化知识编译。
