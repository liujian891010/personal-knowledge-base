# v1.0.43 应用内移动笔记 API 设计

## 目标

为应用内移动 Markdown 笔记提供独立 API，避免用户通过文件系统手动移动后被同步层误判为 `delete + new`。

## API

### Desktop CLI

```bash
pkb-desktop-sync move-workspace-note --file-id <file_id> --path <workspace-relative-path> [--now-ms <ms>]
```

### Bridge

```http
POST /api/workspace/files/:fileId/move
POST /api/workspace/notes/:fileId/move

{
  "path": "Archive/Meetings/XXX.md"
}
```

## 语义

- `file_id` 保持不变，只更新 `filemap.json` 中同一记录的 `path` 和 `updated_at`。
- `path` 必须是 workspace 相对路径，禁止绝对路径、`..`、`.noteapp/*`、`.ai/raw/*` 等保留路径。
- 目标后缀不是 `.md` / `.markdown` 时自动补 `.md`。
- 目标路径若已被其他未删除 filemap 记录占用，或磁盘上已有不同文件，操作失败。
- 移动成功后刷新搜索索引和双链索引；bridge 负责刷新 workspace files snapshot 和 sync shell snapshot。
- 现有 `rename-workspace-note` 保持“仅改文件名、不跨目录”的兼容语义。
