# v1.0.43 V1 入口策略冻结记录

## 主导航开放入口

V1 主导航当前只开放已接入真实工作流的页面：

| 入口 | 状态 | 说明 |
| --- | --- | --- |
| 笔记库浏览 | 开放 | 读取当前 active workspace 的文件树与编辑视图。 |
| AI 文档 | 开放 | 读取当前 active workspace 的文档上下文。 |
| 图谱 | 开放 | 读取当前 active workspace 的真实 links 数据，渲染当前笔记 outgoing/backlinks 邻接图。 |
| 回收站 | 开放 | 读取当前 active workspace 的回收站数据。 |
| 设置 | 开放 | 工作区 registry、AI 配置、本地设置统一入口。 |

## 暂不作为主导航入口

以下页面代码可以保留，但在完成对应任务前不进入主导航：

| 入口 | 当前策略 | 重新开放条件 |
| --- | --- | --- |
| 同步状态 | 隐藏 | 完成 `V1043-M1-05`，保存后待同步提示可以引导到可执行同步动作。 |
| 冲突页 | 不进主导航；由同步冲突提示跳转 | `V1043-M1-06` 已提供替代入口；后续若要进主导航，需要补齐更完整的冲突合并/保留流。 |
| AI Wiki | 隐藏 | 完成 `V1043-M4-05` 到 `V1043-M4-06`，端到端编译和问答入口稳定。 |

## 工作区入口原则

- 顶部工作区切换器、设置页工作区列表、首次进入的 WorkspaceGate 必须共用 `/api/workspaces/*` registry 模型。
- 前端不再通过设置页调用旧 `/api/workspace/root` 或 `/api/workspace/select-folder` 单工作区 API。
- 切换 active workspace 后必须刷新本地设置缓存、文件列表缓存和当前页面 key，避免旧 workspace 数据残留。

## 同步与冲突替代入口

- `V1043-M1-05`：笔记编辑页显示“本地变更待同步”提示，并执行当前同步 primary action，例如提交本地变更或拉取远端基线。
- `V1043-M1-06`：提交冲突或拉取后产生冲突副本时，笔记编辑页的冲突提示跳转到冲突处理页；冲突处理页可查看本地冲突副本并清理全部冲突副本。
