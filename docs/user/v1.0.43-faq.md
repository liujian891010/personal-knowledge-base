# NoteAI V1 FAQ

Version: v1.0.43

## General

### Is NoteAI cloud-first?

No. V1 is local-first. Your workspace folder is the primary working copy. Sync exists to move encrypted changes between devices.

### Does removing a workspace from the app delete my files?

No. Removing a workspace from the app removes it from the local workspace registry. It does not delete the folder on disk.

### Does V1 auto-update?

No. V1 uses manual upgrades. Download the next signed Windows installer and run it over the existing installation. To roll back, run the previous signed installer.

## Sync And Encryption

### What does E2EE protect?

E2EE protects synced note and attachment blob plaintext. The server and object storage receive ciphertext blobs.

### What metadata can the server still see?

The server can see metadata required for sync, such as account, device, vault, revision, file/version identifiers, blob IDs, hashes, sizes, modified times, and request timing.

### Can NoteAI recover my encrypted data if I lose access?

Only if you still have an unlocked device, or you have both the recovery package and recovery phrase. Without those materials, the service cannot recover encrypted content.

### Is the recovery phrase enough by itself?

No. The recovery phrase unlocks the recovery package. You need both the phrase and the package.

### Where is the vault key stored?

The vault key is stored locally through the desktop secure storage path when available, and may be held in process memory while unlocked. It is not uploaded to the sync server.

## File Versions

### When is a file version created?

A version can be created after a successful sync commit or a manual checkpoint. Autosave drafts do not create cloud file versions.

### What does pinning a version do?

Pinning marks the version for retention so normal cleanup rules do not remove it.

### What happens when I restore an old version?

The old content is written back into the current file and a new commit is created. The entire workspace is not rolled back.

### Does renaming a note break version history?

No. App-driven rename and move operations preserve the stable file identity, so history follows the file.

## AI

### Are AI calls covered by sync E2EE?

No. E2EE protects sync storage. If you ask an external AI provider to process selected context, that context is sent to the provider under that provider account's policy.

### Is my AI key synced?

No. The AI key is stored locally in `.noteapp/settings.json` and is not written to sync data.

### Can AI silently change my notes?

No. V1 AI writeback uses preview and confirmation. Inserting into the current note writes through the editor/draft flow, and creating a new knowledge page creates a normal workspace page.

### Which AI files sync?

`.ai/wiki/`, `.ai/index.md`, and `.ai/AGENTS.md` can sync as normal encrypted workspace files. `.ai/raw/` and `.ai/log.md` are local-only by default.

## Troubleshooting

### What should I do if the desktop bridge fails?

Export a desktop diagnostics package from the top bar. The package includes runtime info, bridge health, dependency health, logs, and bridge state previews.

### Can I share diagnostics publicly?

No. Treat diagnostics as confidential because they can include local paths, account state, workspace registry state, and error messages.

### What should I verify before a release upgrade?

Use a signed installer, keep the previous signed installer for rollback, close NoteAI before installing, and export diagnostics if the bridge fails after upgrade.
