# 仓库初始化清单 v1

## 1. 文档目标

本清单用于在正式分配多 Agent 任务前，先把仓库骨架、目录结构、部署约束、基础文档和占位文件初始化好，避免后续并行开发时频繁移动目录。

---

## 3. 第 0 批必须完成项

### 3.1 根目录基础文件

建议初始化：

1. `README.md`
2. `.gitignore`
3. `docs/architecture/README.md`
4. `docs/contracts/README.md`
5. `docs/testing/README.md`

### 3.2 部署目录基础文件

#### `apps/frontend/noteapp-web/`

至少准备：

1. `.cicd.env`
2. `README.md`
3. 如果走预构建静态资源，可预留 `dist/`

建议 `.cicd.env` 内容：

```bash
cicd_monorepo_type='static'
cicd_monorepo_name='noteapp-web'
# cicd_build_static='false'
```

#### `apps/backend/noteapp-server/`

至少准备：

1. `.cicd.env`
2. `README.md`
3. `requirements.txt`
4. `config/nacosConfig.py`

建议 `.cicd.env` 内容：

```bash
cicd_monorepo_type='python'
cicd_monorepo_name='noteapp-server'
```

建议 `requirements.txt` 初始包含：

1. `fastapi`
2. `uvicorn`
3. `pydantic`
4. `sqlalchemy` 或同类 ORM

`config/nacosConfig.py` 必须保留构建脚本可替换字段。

## 7. 初始化执行顺序

### 步骤 1：搭目录

1. 建立 `apps/`
2. 建立 `clients/`
3. 建立 `packages/`
4. 建立 `tests/`
5. 建立 `docs/`

### 步骤 2：补部署必要文件

1. 为 `apps/frontend/noteapp-web/` 写 `.cicd.env`
2. 为 `apps/backend/noteapp-server/` 写 `.cicd.env`
3. 初始化 `requirements.txt`
4. 初始化 `config/nacosConfig.py`

### 步骤 3：补共享契约占位

1. 在 `packages/protocol/` 初始化 schema 和 fixtures
2. 在 `docs/contracts/` 建立对应说明

### 步骤 4：补模块骨架

1. 初始化 `packages/vault-core/`
2. 初始化 `packages/ai-core/`
3. 初始化 `packages/test-fixtures/`

### 步骤 5：补客户端占位

1. 初始化 `clients/desktop/`
2. 初始化 `clients/mobile/`

---

## 8. 初始化完成后的检查项

### 8.1 MonoRepo 规范检查

1. 是否采用 `apps/frontend/*` 和 `apps/backend/*` 结构
2. 每个部署子项目是否有 `.cicd.env`
3. 后端是否符合 Python 项目要求
4. 前端是否明确 static 构建方式

### 8.2 协议边界检查

1. 共享 schema 是否集中在 `packages/protocol/`
2. 是否避免多处重复定义 DTO

### 8.3 所有权检查

1. 是否给每个目录指定 owner
2. 是否明确不可越权修改边界

## 10. 初始化阶段不要做的事

1. 不要一开始拆多个后端服务
2. 不要一开始接入过多 UI 页面
3. 不要在前后端各自维护一套协议定义
4. 不要把桌面端、移动端强行塞进当前部署子项目
5. 不要让多个 Agent 同时修改 `packages/protocol/`

---

## 11. 一句话执行建议

先把目录、部署占位、协议目录和 owner 划清楚，再开始写功能；否则并行开发越早开始，后期重构成本越高。
